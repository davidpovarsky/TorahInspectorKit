## Meaningful target contract

The app's original host exposes Commentaries, Links and Notes. A target for a loaded commentary group, related source or note retains the exact original group/row value and its panel/focus/repository publication. A note reveal does not invoke editing or deletion. Related Documents is not advertised by this app's legacy host merely because the Kit declares that tool.

The retained operation consumes its applying phase before external validation or an original setter. It rechecks the same source around callback-bearing work. A route-owned tool or expansion write must advance the corresponding original publication exactly once. An ordinary equal write, ABA, source replacement, nested invocation or retired lifetime rejects the retained operation. A collapsed group first uses the original expansion callback, then requires a strictly newer original layout publication before the original scroll callback.

The selected tool or completed callback is insufficient for an app acknowledgement. The Kit exposes readiness for an independent original control/row witness; the app must still retain its Reader/backend/window/deadline and actual host attachment, prove visibility, and report through its original transaction. The app-side callback, UIKit and system-delivery acceptance is a separate packet.
